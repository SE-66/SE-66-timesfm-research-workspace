Open-source infrastructure

DevCloud combines a Gitea Git plane, Supabase data plane, Traefik routing plane, and a managed container runtime behind one project model. This console only enables actions that the connected control plane actually supports.

Operational boundary

  • Single-admin, single-node control plane.
  • Real private repositories through Gitea.
  • Real public-OCI-image deployments through the Docker runtime adapter.
  • Optional official self-hosted Supabase data plane.
  • No fake multi-tenant IAM, global edge, or production secret vault.
