        Operating rules

        What this builder enforces

        • Research established open-source solutions before substantial implementation.
        • Prefer maintained, documented, compatible projects over rebuilding generic functionality.
        • Do not treat public GitHub source as automatically reusable.
        • Record license and integration decisions before generated code uses a candidate.
        • Never embed service-role keys, provider tokens, or other secrets in generated source.
        • Never report generated projects as tested when no execution sandbox has run them.
