Execution boundary

What this app does

This outer interface provides navigation, guidance, license context, the iframe container, and an optional research log. It does not run TimesFM, proxy CSV uploads, or receive the CSV uploaded inside the Space.

Files uploaded inside the embedded interface are handled by the third-party Hugging Face Space and its hosting environment.

License boundary

Research use

The google-research/timesfm source repository is Apache-2.0. TimesFM 3.0 pretrained weights are distributed separately under timesfm-non-commercial-license-v1.0 and are restricted to non-commercial, non-production use.

Review the current official repository and model card before relying on the model in a new workflow.

Research protocol

PhD Experiment Mode

Protocol labels

B0 and C1–C5 are research-protocol labels; the cards below do not execute forecasts. The optional Supabase log can record notes against these labels.

B0

Baseline zero-shot

Reference TimesFM-3 forecast on the original series.

C1

Volatility regimes

Compare forecast behavior across predefined volatility states.

C2

Exogenous covariates

Evaluate multivariate context such as benchmarks or macro series.

C3

Event windows

Inspect behavior around scheduled earnings, releases, or policy dates.

C4

Horizon sensitivity

Measure forecast and uncertainty behavior across multiple horizons.

C5

Rolling backtests

Use walk-forward origins for repeatable out-of-sample evaluation.
