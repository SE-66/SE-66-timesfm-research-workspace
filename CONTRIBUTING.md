# Contributing

For substantial changes follow this sequence:

**Inspect → Research → Verify license → Understand → Integrate → Build → Test → Verify**

Before introducing a dependency, prefer the original project repository and official registry/documentation. Do not copy public source merely because it is visible. Keep integrations behind clear boundaries and update `OPEN_SOURCE_COMPONENTS.md` when a significant external component is added.

Run `npm run check` before proposing changes.
